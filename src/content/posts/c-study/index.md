## 入门

### 初始模板

- stdio.h 是标准输入输出头文件的缩写，其包含到各种标准 C 库函数的连接。
- `return 0;`：从 main() 返回 0 表示成功终止。C 中关系/逻辑表达式成立时产生 1，不成立产生 0；而表达式作为条件时，0 被视为假，任何非 0 值都被视为真。main() 的退出状态则是另一套约定，0 表示成功。

```c
#include <stdio.h>

int main()
{
	[可替换部分]

	return 0;
}
```

### 赋值和初始化

- 程序设计中 a=b 与 b=a 的意思完全相反。
- a=b 把 b 的值交给 a，b=a 把 a 的值交给 b。
- 变量初始化：在变量定义时发生的赋值，所有变量在第一次被使用前应该被赋值一次。
- 初始化一般形式：<类型名称><变量名称> = <初始值>。
- 赋值不是证明两边相等，而是“算右边，把结果放到左边”。

`int price = 0;`

- 这一行，定义了一个变量。变量的名字是 price，类型是 int，初始值是 0。

- 所有的变量必须具有确定的数据类型。
- 数据类型表示在变量中可以存放什么样的数据，变量中只能存放指定类型的数据，程序运行过程中也不能改变变量的类型。
- C99 可以在代码任意位置定义变量，ANSI C 必须在代码开头定义。

### char

1. 基本概念
   `char` 是 C 语言的一种基本整数类型，通常用于存储单个字符的编码值。

```c
char ch = 'A';
```

注意：

- `'A'`：字符常量，使用单引号。
- `"A"`：字符串字面量，使用双引号。
- `char` 通常占用 1 字节。
- 在常见的 ASCII 兼容环境下，可以用 `char` 保存英文字母、数字字符及常见英文符号。

```c
char a = 'A';
char b = '7';
char c = '@';
```

其中，`'7'` 是字符，不等同于整数 `7`。

2. 输入与输出
   | 操作 | 格式控制符 | 示例 |
   | ----------- | ----- | ------------------- |
   | 输入单个字符 | `%c` | `scanf("%c", &ch);` |
   | 输出单个字符 | `%c` | `printf("%c", ch);` |
   | 输出字符对应的整数编码 | `%d` | `printf("%d", ch);` |

完整示例：

```c
#include <stdio.h>

int main()
{
    char ch;

    scanf("%c", &ch);

    printf("字符：%c\n", ch);
    printf("编码：%d\n", ch);

    return 0;
}
```

输入：`A`
输出：`字符：A 编码：65`

- `printf` 的 `%c` 按字符形式输出，而 `%d` 按十进制整数形式输出。
  注意： `printf("%f", ch)` 不正确。`%f` 要求对应的参数为 `double`，而 `char` 传入 \* `printf` 时会提升为 `int`，两者类型不匹配。

3. ASCII 编码
   ASCII 是一种字符编码标准，常见英文字母、数字和符号都有对应的数值。

| 字符  | ASCII 编码 |
| ----- | ---------- |
| `'0'` | 48         |
| `'9'` | 57         |
| `'A'` | 65         |
| `'Z'` | 90         |
| `'a'` | 97         |
| `'z'` | 122        |

需要掌握的规律：

- `'0'` 到 `'9'` 编码连续。
- `'A'` 到 `'Z'` 编码连续。
- `'a'` 到 `'z'` 编码连续。
- **同一个英文字母的小写编码比大写大 32。**

例如：

```c
char ch = 'a';

printf("%c\n", ch);       // a
printf("%d\n", ch);       // 97
printf("%c\n", ch - 32);  // A
```

4. 字符的运算
   由于 `char` 属于整数类型，所以可以参与整数运算。

```c
char ch = 'A';

printf("%c\n", ch + 1);  // B
printf("%d\n", ch + 1);  // 66

char j;
int k = 4;
j == '0' + k;
```

但是，字符运算实际上是对编码值进行运算，并不是对文字本身进行处理。

**大小写转换**
在 ASCII 编码下，小写字母转换为大写：

```c
char ch = 'q';
ch = ch - ('a' - 'A');

printf("%c\n", ch);  // Q
```

这里 `'a' - 'A'` 的结果为 `32`。
这种写法适用于题目保证输入为小写英文字母的情况，例如洛谷 P5704。

**数字字符转换为整数**
```c
char ch = '7';
int n = ch - '0';
printf("%d\n", n);  // 7
```

因为数字字符的编码连续，所以：'7'-'0'=55-48=7
这是之后处理数字字符时非常常见的技巧。

5. `scanf("%c")` 的注意事项
   与 `%d` 不同，`%c` 默认不会自动跳过空格、制表符和换行符。

例如：
```c
int n;
char ch;

scanf("%d", &n);
scanf("%c", &ch);
```

输入：

```
12
A
```

第二次 `scanf` 可能读到输入 `12` 后留下的换行符，而不是 `A`。
常见解决方法：

```c
scanf(" %c", &ch);
```

`%c` 前面的空格会让 `scanf` 跳过前面的空白字符。
不过，如果题目本身要求读取空格，就不应该这样写。

6. 常见转义字符
   部分特殊字符需要使用反斜杠 `\` 表示。

| 写法   | 含义             |
| ------ | ---------------- |
| `'\n'` | 换行             |
| `'\t'` | 水平制表符       |
| `'\\'` | 反斜杠           |
| `'\''` | 单引号           |
| `'\0'` | 空字符，数值为 0 |

例如：
```c
char ch = '\n';

printf("Hello%cWorld", ch);
```

输出：
```
Hello
World
```

- `\n`：换行

```c
printf("Hello\nWorld");
```

输出：
```text
Hello
World
```

也可以单独使用：
```c
printf("\n");
```

表示换行，不输出其他文字。

- `\t`：水平制表符
```c
printf("A\tB\tC\n");
```

输出效果类似：
```text
A       B       C
```

`\t` 不是固定数量的空格，而是移动到下一个制表位。
因此，不同长度的数字之间，实际产生的空白宽度可能不同。

- 利用计数器控制换行
  **示例：每输出 5 个素数换行。**

```c
if (isPrime == 1) {
    cnt++;
    printf("%d\t", x);

    if (cnt % 5 == 0) {
        printf("\n");
    }
}
```

其中：

- `cnt++`：记录已经输出的素数个数。
- `printf("%d\t", x)`：输出素数，并移动到下一个制表位。
- `cnt % 5 == 0`：判断已输出数量是否为 5 的倍数。
- `printf("\n")`：每输出 5 个素数后换行。

为什么需要先执行 `cnt++`？
因为计数应当表示已经输出的数字数量。如果 `cnt` 初始为 0，却在递增之前直接判断：

```c
if (cnt % 5 == 0)
```

则第一次检查时 `0 % 5 == 0` 就成立，可能导致提前换行。

- 使用 printf 字段宽度对齐（补充）
  对于数字表格，也可以使用字段宽度：

```c
printf("%4d", x);
```

`%4d` 表示数字输出时至少占用 4 个字符宽度，默认右对齐。
例如：
```c
printf("%4d%4d%4d\n", 2, 17, 101);
```

输出：
```text
   2  17 101
```

还可以使用：

```c
printf("%-4d", x);
```

表示至少占用 4 个字符宽度，左对齐。

区别：
- `\t`：按照制表位移动，方便简单分隔。
- `%4d`：指定最小输出宽度，更适合对齐数字列。
- `\n`：控制何时开始新的一行。

**总结**
- `\n` 与 `\t` 都属于转义序列，可以写在字符串内部。
- 利用计数变量配合取余运算，可以实现每输出固定数量的数据便换行。
- 当数字长度不一致时，使用 `printf` 的字段宽度通常比单纯使用 `\t` 更容易实现整齐的数字列。

### 7. 易错点

| 错误或疑问                 | 正确理解                          |
| -------------------------- | --------------------------------- |
| `char ch = "A";`           | 单个字符应写成 `'A'`              |
| `'5' == 5`                 | 不相等，ASCII 中 `'5'` 是 53      |
| `printf("%d", 'A')`        | 输出整数编码 65                   |
| `printf("%c", 65)`         | ASCII 环境下输出字符 A            |
| `printf("%f", ch)`         | 类型不匹配，属于未定义行为        |
| 一个 `char` 能否存储汉字？ | 通常不能完整存储 UTF-8 编码的汉字 |

## 整数 浮点数

**定义**

- 浮点数：带小数点的数。
- 例：10 是整数，10.0 是浮点数。
- C 语言中带小数点的数与不带小数点的数是完全不同的两个数 (如 10 与 10.0)。

### 示例

- 整数运算：`printf("%d\n", 10/3)` 得到 3 (只保留整数部分)
- 采用浮点数：`printf("%f\n", 10.0/3)` 得到 3.33...

**应用：身高转换的问题程序**

- 计量单位不同：中国公制，美国等使用英制 [几尺几寸]。(如：五尺七寸 -> (5 + 7 / 12) \* 0.3048 = 1.7018 m。)
- \"：用于让程序输出双引号本身。

```c
printf(
	"请分别输入身高的英尺和英寸, "
    "如输入\"5 7\"表示5英尺7英寸: "
);

int foot;
int inch;

scanf("%d %d", &foot, &inch);

printf("身高是%f米。\n", ((foot + inch / 12) * 0.3048));
```

**问题及原因**

- 执行表现后为英寸部分丢失，实则是小数问题。
- 两个整数的运算的结果只能是整数，若不是，结果会丢失小数部分。

**改进方案**

- 当浮点数和整数放到一起运算时，C 会将整数转换为浮点数进行浮点数的运算。
- 有浮点数参与运算或计算结果不是整数时，%d 需要改为 %f。

1. 将 12 替换为 12.0：`printf("身高是%f米。\n", ((foot + inch / 12.0) * 0.3048));`
2. 将 int 这一整型变量替换为 double：`double foot; double inch;`

### 数据类型

- 整数的变量、输出、输入：

```c
int
printf("%d",...)
scanf("%d",...)
```

- 浮点数的变量、输出、输入：

```c
double
printf("%f",...)
scanf("%lf',...)
```

## 表达式

### 定义

一个表达式是一系列算子和运算符的组成，用来计算一个值。

### 运算符和算子

- 运算符：指进行运算的动作。如 ("+", "-")
- 算子：指参与运算的值，可能是常数、变量、或是一个方法的返回值。

### 示例

```c
#include <stdio.h>
int main()
{
    int hour1, minute1;
    int hour2, minute2;

    printf("请输入第一个时间 (小时 分钟): ");
    scanf("%d %d", &hour1, &minute1);
    printf("请输入第二个时间 (小时 分钟): ");
    scanf("%d %d", &hour2, &minute2);

    printf("时间差是: %d 小时 %d 分钟\n", hour2 - hour1, minute2 - minute1);

    return 0;
}
```

**问题**

- 直接分别减，会出现分钟错位的情况 (如 1：40 和 2：10 的差 输出 1 小时 -30 分)

**改进方案**

- 设计更准确的办法计算，将单位统一到小时或分钟:

* 以分钟为单位：小时\*60+分钟
* 以小时为单位：小时+分钟/60
* 以分钟为单位的示例：

```c
int hour1, minute1;
int hour2, minute2;

printf("请输入第一个时间 (小时 分钟): ");
scanf("%d %d", &hour1, &minute1);
printf("请输入第二个时间 (小时 分钟): ");
scanf("%d %d", &hour2, &minute2);

printf("时间差是: %d 分钟\n", (hour2 - hour1) * 60 + minute2 - minute1);
```

- 以 x 小时 x 分钟的方式显示 -> 整数除法 + %取余：

```c
int hour1, minute1;
int hour2, minute2;

printf("请输入第一个时间 (小时 分钟): ");
scanf("%d %d", &hour1, &minute1);
printf("请输入第二个时间 (小时 分钟): ");
scanf("%d %d", &hour2, &minute2);
```

### 复合赋值

- 算术运算符可以和赋值运算符"="结合起来，形成复合赋值运算符 "+="、"-="、"\*="、"/="、"%="。
- 两个运算符中间不要有空格。
- 例：`total += 5` 等同于 `total = total + 5`
- `total += amount + 10` 等同于 `total = total + (amount + 10)`

* `total += (sum+100)/2;` 等同于· `total = total + (sum+100)/2;`
* `total *= sum+12;` 等同于 `total = total * (sum+12);`
* `total /= 12+6;` 等同于 `total=total / (12+6);`

- 递增递减运算符："++" "--"，单目运算符，算子必须是变量，作用是给对应变量 +1 或 -1。

* 示例：`count++` 等同于 `count += 1` 等同于 `count = count + 1`

### 前缀后缀

- "++" "--" 可以放在变量的前面，叫做前缀形式，也可以放在变量的后面，叫做后缀形式。
- a++ 与 ++a 的值不同，a++ 的值是 a+1 以前的值，++a 的值是加了 1 以后的值。
- 示例：`int a = 5; int b = a++;` 最终结果: `a = 6, b = 5`

* `int a = 5; int b = ++a;` 最终结果：`a = 6, b = 6`
* a++：先用后加 ++a：先加后用

**应用**

```c
int a;
a = 10;

printf("a++=%d\n", a++);
printf("a=%d\n", a);

printf("++a=%d\n", ++a);
printf("a=%d\n",a);
```

输出: `a++=10, a=11, ++a=12, a=12`

### 交换两个变量

- 程序是按步执行的，表达的是顺序执行的动作，而不是关系。
- 错误示例: "a = b; b = a" 正确示例："t = a; a = b; b = t" (套路)

### 级联的 if/else

1. 多个独立 `if`，每个 `if` 都会单独进行判断。
2. `if - else if - else`。用于多个互斥情况中只选择一个。
   特点：

- **一旦某个条件成立，后面的分支不再判断；**
- 最多只执行其中一个分支；
- 后面的条件可以利用前面已经排除的信息。

例如成绩转换，可采用级联的 if/else：

```c
if (score >= 90) {
    printf("A\n");
} else if (score >= 80) {
    printf("B\n");
} else if (score >= 70) {
    printf("C\n");
} else if (score >= 60) {
    printf("D\n");
} else {
    printf("E\n");
}
```

无需再写：`80 <= score < 90`。

3. 独立 `if` 与 `else if` 的区别

- 多个独立 `if`，每个条件都会判断；可能执行多个分支：

```c
if (condition1) { ... }
if (condition2) { ... }
if (condition3) { ... }
```

而 `if - else if - else`，属于同一条分支链；最多执行一个分支：

```c
if (condition1) {
    ...
} else if (condition2) {
    ...
} else {
    ...
}
```

直观对比：

```c
if (score >= 60)
    printf("D\n");
if (score >= 70)
    printf("C\n");
if (score >= 80)
    printf("B\n");
if (score >= 90)
    printf("A\n");
```

若 `score = 95`，四个条件全部成立，会输出：`DCBA`。因此这种情况应该使用 `else if`。

### 嵌套的 if/else

- 当 if 的条件满足或者不满足的时候，要执行的语句也可以是一条 if 或 if-else 语句，这就是嵌套的 if 语句。
- else 的匹配：else 总是和最近的 if 匹配 (有大括号分隔除外)。缩进不能暗示 else 的匹配。

### while 循环

- 与 if 的不同：if 是一次性的，while 是反复不断的。

### do-while 循环

> 在进入循环的时候不做检查，而是在执行完一轮循环体的代码之后，再来检查循环的条件是否满足，如果满足则继续下一轮循环，不满足则结束循环。

- 区别：do-while 先进循环体后判断条件，while 先判断条件再进循环体。

**一般形式**

```c
do
{
    <循环体语句>

```

### 猜数游戏

**随机数**

- 每次召唤 rand() 就会得到一个随机的整数。
- rand() 用于生成伪随机数，srand() 用于初始化随机数种子。通常在程序开始时执行一次 srand(time(0))，使不同时间运行程序时通常产生不同的随机数序列。文件头要包含 <stdlib.h> 和 <time.h>。

- 使用样例：

```c
#include <stdlib.h>  // rand、srand
#include <time.h>    // time

srand((unsigned int)time(NULL)); // 使用当前时间初始化随机数生成器，让程序多次运行时通常得到不同的结果。
int number = rand() % 100 + 1; // 生成一个伪随机整数，并把结果限制在 1～100。
printf("%d\n", number); // 输出这个伪随机整数。
```

- % 100：x % n 的结果是 [0, n-1] 的一个整数。

**题目**
计算机生成一个 1～100 的随机整数，用户不断输入数字进行猜测。

- 猜大时提示“大”；
- 猜小时提示“小”；
- 猜中时结束游戏；
- 输出总猜测次数，包括最后猜中的一次。
- 利用二分法，最多 7 次可猜出正确结果 (2 的 6 次方为 64，2 的 7 次方是 128)。

**参考算法**

1. 计算机随机生成一个数，保存在变量 `number` 中。
2. 定义计数变量 `count`，初始化为 `0`。
3. 让用户输入一个数字 `a`。
4. 将 `count` 加 `1`，记录本次猜测。
5. 判断 `a` 与 `number` 的大小关系：
   - 如果 `a > number`，提示“猜大了”；
   - 如果 `a < number`，提示“猜小了”。
6. 如果 `a != number`，返回第 3 步，继续猜测。
7. 否则说明猜中，输出成功提示及猜测次数，程序结束。

**while（个人解法）**

```c
int count = 0;
int a;

scanf("%d", &a);

while (a != number) {
    if (a > number) {
        printf("大\n");
    } else {
        printf("小\n");
    }

    count++;
    scanf("%d", &a);
}

count++;
printf("猜中！共猜了 %d 次\n", count);
```

执行特点：

1. 第一次输入发生在循环之前。
2. 每轮循环先判断 `a != number`。
3. 猜错则进入循环，输出提示、计数并重新输入。
4. 猜中后退出循环，在循环外补计最后一次猜测。

因此，`count++` 分别出现在循环内外。

**do-while（参考解答）**

```c
int count = 0;
int a;

do {
    scanf("%d", &a);
    count++;

    if (a > number) {
        printf("大\n");
    } else if (a < number) {
        printf("小\n");
    }

} while (a != number);

printf("猜中！共猜了 %d 次\n", count);
```

执行特点:

1. 先执行循环体，再判断条件。
2. 每次循环都完成一次输入及计数。
3. 猜大、猜小都继续循环。
4. 猜中时条件为假，退出循环。
5. 不需要在循环结束后额外补计一次。

**解题问题**

1. 错误地使用多个独立 `while`，改进：

- 使用一个 `while (a != number)` 控制游戏是否继续。
- 在循环内部使用 `if / else` 判断猜大还是猜小。
- 每次猜错后通过 `scanf()` 重新读取 `a`，使循环条件有机会改变。
- 猜中后的提示只需要执行一次，不应该使用 `while`。

2. 猜测次数没有包含最后猜中的一次，改进：
   方法一：使用 `while`。

- 在循环内部统计猜错次数。
- 循环退出后，再执行一次 `count++`，计入最后猜中的一次。
  方法二：使用 `do-while`。
- 每次输入后立即 `count++`。
- 无论猜对还是猜错，都记录一次猜测。
- 不需要在循环结束后额外补计。

3. 使用随机数函数时缺少头文件

**总结**

- `while`：先判断，再执行。
- `do-while`：先执行，再判断，至少执行一次。
- 猜数游戏至少需要输入一次，因此 `do-while` 更符合游戏流程。
- 两种写法均可正确实现，关键是保证循环条件最终能够变为假。
- `count` 应记录实际猜测次数，而非仅记录猜错次数。
- 循环负责重复猜测，`if / else` 负责判断猜测结果。

### 算平均数

**题目**
让用户输入一系列的正整数，最后输入-I表示输入结束，然后程序计算出这些数字的平均数，输出输入的数字的个数和平均数。

**参考算法**

1. 初始化 `sum = 0`、`count = 0`。
2. 读入整数 `number`。
3. 如果 `number != -1`，则将其累加到 `sum`，并将 `count` 加 1，然后返回第 2 步。
4. 如果 `number == -1`，则结束输入，计算并打印 `sum / count`（注意使用浮点运算）。

**实现要点**

- `sum += number` 等价于 `sum = sum + number`。
- `count++` 记录有效输入的个数，结束标志 `-1` 不参与计数。
- `1.0 * sum / count` 利用浮点数参与运算，避免整数除法丢失小数。
- 计算平均数应放在循环结束之后，此时 `sum` 和 `count` 才是最终值。
- `while` 可在循环前读入第一个数；`do-while` 可在循环内读入，再通过 `if` 排除结束标志。

**个人解法**

```c
int sum = 0;
double count = 0;
int number;

scanf("%d", &number);
while (number != -1) {
    count++;
    sum = sum + number;
    scanf("%d", &number);
}

if (number == -1) {
    double pjs = sum / count;
    printf("%f", pjs);
}

return 0;
```

**解题问题**
最初在循环之前执行 `double pjs = sum / count;`，由于 `sum` 和 `count` 均为 0，得到 `nan`。将平均数计算移至循环结束之后即可修正。

**计算方式改进**
将下面部分

```c
double count = 0;
double pjs = sum / count;
```

替换为

```c
int count = 0;
printf("%f\n", 1.0 * sum / count);
```

- 优势：1.0 是浮点数，保证乘法和后续除法采用浮点运算，不会因为 sum 与 count 都是整数而丢失小数。

**边界情况**
如果第一次输入就是 `-1`，则 `count == 0`，此时无法计算平均数。应在计算前检查 `count > 0`。

```c
int x;

scanf("%d", &x);
```

### 整数求逆

**整数的分解**

- 对一个整数做 %10 的操作，就得到了它的个位数。
- 对一个整数做 /10 的操作，就去掉了它的个位数。
  ......以此类推。

**要求**

1. 输入一个正整数，输出逆序的数。
2. 结尾 0 的处理。

**算法**

- 核心思路：从原数中逐次取出个位，并在已有结果后面追加该数字。

1. 输入整数 `number`。
2. 初始化逆序结果 `result = 0`。
3. 取出原数的个位，保存在 `t` 中。
4. 将已有结果乘以 10，再加上 `t`。
5. 将 `number` 除以 10，去掉已经处理过的个位。
6. 如果 `number > 0`，继续重复第 3～5 步。
7. 输出逆序结果 `result`。

**三个核心运算**

```c
t = number % 10;          // 取出个位
result = result * 10 + t; // 在已有结果后面追加一位
number /= 10;             // 删除已处理的个位
```

其中：

- `% 10`：提取个位。
- `result * 10`：使已有数字向左移动一位，腾出个位。
- `+ t`：将本轮取得的数字放到个位。
- `/= 10`：不断缩小原数字，使循环最终结束。

**个人解法：do-while**

```c
#include <stdio.h>

int main()
{
    int number, t;
    int result = 0;

    scanf("%d", &number);

    do {
        t = number % 10;
        number /= 10;
        result = result * 10 + t;
    } while (number > 0);

    printf("%d\n", result);

    return 0;
}
```

**课程参考：while**

```c
#include <stdio.h>

int main()
{
    int x;
    scanf("%d", &x);

    int digit;
    int ret = 0;

    while (x > 0) {
        digit = x % 10;
        ret = ret * 10 + digit;
        printf("x=%d,digit=%d,ret=%d\n", x, digit, ret);
        x /= 10;
    }

    printf("%d", ret);

    return 0;
}
```

- 参考答案中循环内的 `printf` 用于调试，可以观察每轮变量的值。正式输出逆序结果时应将该语句注释或删除。

**解题问题**

1. 最初尝试交换数字的位置

```c
result = (number % 10) * 10 + number / 10;
```

问题：

- 对 `12` 可以得到 `21`。
- 对 `123` 却得到 `42`。
- 算法只能直接交换两位数的位置，无法处理任意位数。

原因：试图在一次计算中完成逆序，而没有利用循环逐位构造结果。

2. 循环条件不变化，导致无限循环
   早期写法：

```c
do {
    result = (number % 10) * 10 + number / 10;
} while (number >= 10);
```

其中 `number` 始终没有改变。
当输入大于等于 10 时，循环条件一直成立，无法结束。

改进：每轮通过 `number /= 10` 缩小数字，使其最终变为 0。

3. 错误地尝试修改 result，而没有继续处理 number
   曾尝试：

```c
result = (result % 10) * 10 + result / 10;
result /= 10;
```

问题：

- 仍然是在尝试交换数字。
- `result /= 10` 会丢弃已经构造出来的数字。
- 没有从 `number` 继续提取下一位。
  应当让 `number` 不断缩小，让 `result` 不断累积。

4. 没有初始化 result
   `result` 需要保存上一轮构造好的结果，因此应初始化为：

```c
int result = 0;
```

之后再逐轮更新：

```c
result = result * 10 + t;
```

不能把未初始化的局部变量直接用于计算。

5. 循环条件设置错误，漏掉最后一位
   曾写成：

```c
} while (number >= 10);
```

输入 `1234` 时：

```text
第 1 轮 → result = 4，number = 123
第 2 轮 → result = 43，number = 12
第 3 轮 → result = 432，number = 1
```

此时 `number >= 10` 为假，循环结束。但最高位 `1` 尚未处理。

正确条件：

```c
} while (number > 0);
```

只要原数还有未处理的正整数部分，就应该继续循环。

**边界情况**

- 输入一位正整数：`do-while` 执行一次后，`number` 变成 0，正常结束。
- 输入 `0`：`do-while` 执行一次，结果仍为 0；参考答案的 `while` 则不执行循环，结果同样为 0。
- 输入 `1200`：逆序结果为整数 `21`，不会保留前导零。
- 负数和逆序后超出 `int` 可表示范围的情况，需要另行处理，本节暂不讨论。

**总结**
本题的关键并不是增加更多变量，而是利用循环完成不固定次数的重复操作。
每次处理一位，使用 result 保存已经完成的部分。

对于类似的循环问题，应当明确：

1. 每轮需要处理什么数据？
2. 已经得到的结果保存在哪里？
3. 下一轮如何获得新的数据？
4. 循环在什么条件下结束？

整数求逆体现了两种同时进行的操作：

- `number /= 10`：不断减少待处理的数据。
- `result = result * 10 + t`：不断构造最终结果。

## 第三种循环 -- for 循环

### 一般格式

```c
for ( 初始条件, 循环条件, 循环每轮的动作) {

}
```

- for 循环像一个计数循环：设定一个计数器，初始化它，然后在计数器到达某值之前，重复执行循环体，而每执行一轮循环，计数器值以一定步进进行调整，比如加1或者减1。
- 例：`for ( count=10; count>0; count-- )` 可以理解成:"对于一开始的 count=10，当 count>0 时，重复做循环体，每一轮循环在做完循环体内语句后，使得 count--。
- 变量初始化：做求和的程序时，记录结果的变量应该初始化为 0，而做求积的变量时，记录结果的变量应该初始化为 1。
- 若某个变量只在循环里被使用了，那么可以把变量的定义写到 for 语句之中。
- 三个表达式不一定要全部存在，每一个表达式都可以省略。
- for 循环和 while 循环可以被相互转化。

### 循环的计算和选择

- `for`：适合计数规律明确的循环，将初始化、循环条件和变量更新集中在一处。
- `while`：先判断再执行，适合根据条件决定是否继续重复。
- `do-while`：先执行再判断，循环体至少执行一次。

**共同点：**

三者均可用于重复执行一组语句，许多问题可以使用不同循环结构实现。

**选择原则：**

1. 计数规律明确，优先考虑 `for`。
2. 需要先执行操作才能检查继续条件，优先考虑 `do-while`。
3. 需要在每轮执行前检查条件，优先考虑 `while`。

这些只是编程经验，不是语法限制。

**注意：**

- 必须保证循环条件最终有机会变为假。
- 注意循环变量是在判断前还是判断后更新。
- 尤其检查循环第一次和最后一次执行的边界。

### 单层循环与嵌套循环：素数判断

1. 单层循环的适用情况
   判断一个固定整数 x 是否为素数：

- 使用一层循环枚举可能的约数。
- 一旦发现 `x % i == 0`，即可确定不是素数。
- 可以使用 `break` 提前退出，避免继续检查。

如果不使用 `break`，程序仍可能得到正确结果，
但会执行不必要的循环。

注意：素数必须大于 1，需排除 x <= 1 的情况。

2. 什么时候需要嵌套循环？
   当问题包含两个层次的重复任务时，可以考虑嵌套循环。  
   例如输出 100 以内的全部素数：

- 外层：依次枚举候选数 x。
- 内层：针对当前 x，枚举可能的约数 i。
- 内层结束后：根据 isPrime 输出符合条件的数字。

3. 关键区别

| 任务                   | 循环结构 | 原因                 |
| ---------------------- | -------- | -------------------- |
| 判断单个整数是否为素数 | 单层循环 | 只需检查一个数字     |
| 输出 100 以内所有素数  | 双层循环 | 需要逐一检查多个数字 |
| 已发现当前数字不是素数 | break    | 立即停止无意义的检查 |

4. 嵌套循环的注意事项

- 内层循环执行完毕后，外层循环才继续下一轮。
- `break` 只退出最近的一层循环。
- 每次检查新的 x，都需要重新初始化 isPrime。
- 循环层数由问题的重复结构决定，不是越多越好。

**总结：**
单层循环解决当前对象内部的重复操作；
嵌套循环解决「重复处理多个对象，而每个对象又需要重复检查」的问题。

### 循环控制

**嵌套循环**

- 示例一：100 内的素数
  - 采用嵌套循环，外层循环寻找候选数字，内层循环判断是否是素数。
  - x = 2: 素数是大于 1 的自然数，且只能被 1 和它自身整除。

```c
#include <stdio.h>

int main()
{
    int x;

    for (x = 2; x <= 100; x++) {
        int i;
        int isPrime = 1; // 假设 x 是素数

        for (i = 2; i < x; i++) {
            if (x % i == 0) {
                isPrime = 0;
                break;
            }
        }

        if (isPrime == 1) {
            printf("%d ", x);
        }
    }

    return 0;
}
```

- 示例二：凑硬币问题

```c
#include <stdio.h>

int main()

    int one, two, five;

                           one, two, five, x);
                }

}
```

```c
int exit = 0;

for (one = 1; one < x * 10; one++) {
```


### break 与 continue

| 语句       | 作用                             | 是否结束整个循环 |
| ---------- | -------------------------------- | ---------------- |
| `break`    | 立即退出当前最内层循环           | 是               |
| `continue` | 跳过本轮循环剩余语句，进入下一轮 | 否               |

**break**

- 用于 `for`、`while`、`do-while` 和 `switch`。
- 在循环中执行后，直接跳到循环后面的语句。
- 在嵌套循环中，只退出所在的最内层循环。

**continue**

- 只能用于循环语句。会跳过**本轮**剩余代码。
- 在 `for` 中仍会执行更新表达式。
- 在 `while` 中会直接重新判断条件。
- 如果跳过了更新循环变量的语句，可能导致无限循环。

**区别**

- `break`：整个循环不做了。
- `continue`：这一轮不做了，下一轮继续。

**作用范围**

- “内层循环”只在存在嵌套循环时才有意义，指位于另一层循环内部的循环。
- `if / else` 不是循环。即使将 `break` 或 `continue` 放在 `if` 内部，也不会改变它们的作用范围。
- `break`：退出最近一层包围它的循环或 `switch`。
- `continue`：跳过最近一层循环的当前轮次，继续下一轮。
- 在嵌套循环中，二者不会自动控制外层循环。

**注意：** `break` 可以用于 `switch`，但 `continue` 不能单独用于 `switch`；如果 `switch` 位于循环中，`continue` 会作用于外面的循环。

**注意：** `continue` 并不能保证循环一定终止，仍需检查循环变量是否正常更新。

### 接力 break 与 goto

**接力 break**

`break` 只能退出最近一层循环，无法直接退出所有嵌套循环。
若需要提前结束多层循环，可以通过标志变量记录状态，并在每层循环中分别检查：

```c
int found = 0;

// 最内层
if (满足条件) {
    found = 1;
    break;
}

// 中间层
if (found == 1) break;

// 最外层
if (found == 1) break;
```

**goto**

goto 是无条件跳转语句。
基本格式：

```c
goto label;

// 其他代码

label:
    语句;
```

其中：

- goto label;：跳转到指定标签。
- label:：定义跳转目标。
- 标签可以自定义名称。
- goto 只能跳转到同一函数内的标签。

在三重循环中：

```c
if (满足条件) {
    goto out;
}

out:
    return 0;
```

可从内层直接跳到全部循环之后，不必通过标志变量逐层退出。

使用建议：

- 普通循环退出：优先使用 break。
- 跳过本轮循环：使用 continue。
- 跳出多重循环：可以使用标志变量接力 break，也可以谨慎使用 goto。
- 复杂的错误处理和集中资源清理：goto 有时也是合理选择。
- 避免用大量 goto 替代正常的条件判断和循环结构。

### 前 n 项求和

**题目**
输入一个正整数 n，计算下列数列的前 n 项之和：
f(n) = 1 + 1/2 + 1/3 + ... + 1/n

**算法设计**

1. 读入正整数 `n`。
2. 定义循环变量 `x = 1`，表示当前计算的项数和分母。
3. 定义累加变量 `h = 0`，保存已经计算的总和。
4. 当 `x <= n` 时，重复：
   - 计算当前项 `1.0 / x`；
   - 将当前项累加到 `h`；
   - 将 `x` 加 1。
5. 循环结束后，输出 `h`。

- 核心：每轮计算一项，并在之前的结果上继续累加。

**个人解法**

```c
    int n;
    scanf("%d", &n);

    int x = 1;
    double h = 0;

    while (x <= n) {
        h += 1.0 / x;
        x++;
    }

    printf("%f", h);
```

**教材参考：for**

```c
int i;
double sum = 0.0;

for (i = 1; i <= n; i++) {
    sum += 1.0 / i;
}
```

**关键知识点**

1. 累加变量

```c
double h = 0;
h += 1.0 / x;
```

等价于：

```c
double h = 0;
h = h + 1.0 / x;
```

- 可以使每轮保留之前的结果，再加入当前项。

2. 整数除法与浮点数除法

```c
1 / x      // 整数除法
1.0 / x    // 浮点数除法
```

- 由于 `x` 是整数，如果使用 `1 / x`，当 `x > 1` 时结果均为 0。使用 `1.0` 可以让表达式采用浮点数除法，保留小数部分。
- 注意：即使将 `h` 定义为 `double`，也不能自动修正 `1 / x` 已经发生的整数除法。

3. 循环顺序

```c
while (x <= n) {
    h += 1.0 / x;
    x++;
}
```

先计算，再递增。如果先执行 `x++`，就会跳过第一项，并可能多计算一项。

4. 循环边界

- `x = 1`：从第一项开始。
- `x <= n`：包括第 n 项。
  当 `x = n + 1` 时，循环条件为假，计算结束。

**解题问题**

1. 不知道如何处理最开始的 1
   只要从 `x = 1` 开始循环，就能统一处理全部项，无须额外写 `h = 1`。

2. 不知道如何保存之前的计算结果
   最初写法：

```c
double h;

while (x <= n) {
    x++;
    h = 1.0 / x;
}
```

其中 `h = 1.0 / x` 每轮都会覆盖之前的结果，并非求和。

改进：

```c
double h = 0;
h += 1.0 / x;
```

利用累加变量保存中间结果。

3. 自增语句放在计算之前
   错误顺序：

```c
x++;
h = 1.0 / x;
```

当 `x` 初始为 1 时，第一次计算的就是 `1/2`，遗漏 `1/1`。应改为先累加，再自增。4. 整数除法导致结果不正确
`1 / x` 会执行整数除法，因此应使用：

```c
1.0 / x
```

之前在「算平均数」中也遇到过相同的类型问题。

**总结**

> 本题使用循环完成具有固定规律的数列求和。

核心步骤：

1. 找出数列的通项规律。
2. 初始化累加变量。
3. 每轮计算当前项。
4. 将当前项加入总和。
5. 更新循环变量，直到计算完第 n 项。

关键区别：

- `h = ...`：覆盖之前的结果。
- `h += ...`：在之前的结果上**继续累加**。

**扩展：一增一减**
建议做法：在循环前引入一个新变量 (如 sign)。而后在循环中令 h 与 sign 相乘，并让 sign = -sign。

### 最大公约数

**穷举法**

- 介绍：
  依次检查所有可能的公约数。
  优点：计算便捷。缺点：计算复杂。

- 算法：

1. 输入正整数 `a`、`b`。
2. 比较两个数，得到较小值 `min`。
3. 从 `i = 1` 开始，逐个检查到 `min`。
4. 如果 `a % i == 0 && b % i == 0`，说明 `i` 是公约数，将其记录下来。
5. 继续增加 `i`，直到检查完全部候选值。
6. 最后记录的公约数即为最大公约数。

- 自解答：while

```c
    int a, b;
    scanf("%d %d", &a, &b);

    int min;

    if (a > b) {
        min = b;
    } else {
        min = a;
    }

    int i = 1;
    int x;

    while (i <= min) {
        if (a % i == 0 && b % i == 0) {
            x = i;
        }

        i++;
    }

    printf("最大公约数为 %d\n", x);
```

- 课程参考：for

```c
    int a, b;
    int min;

    scanf("%d %d", &a, &b);

    if (a < b) {
        min = a;
    } else {
        min = b;
    }

    int ret = 0;
    int i;

    for (i = 1; i <= min; i++) {
        if (a % i == 0) {
            if (b % i == 0) {
                ret = i;
            }
        }
    }

    printf("%d和%d的最大公约数是%d\n", a, b, ret);
```

**辗转相除法**

- 可以不断使用余数替换原来的整数，直到余数为 0。
- 算法：
  如果b等于0，计算结束，a就是最大公约数;
  否则，计算a除以b的余数，让a等于b，而b等于那个余数;
  回到第一步。

- 解答：

```c
    int a, b;
    scanf("%d %d", &a, &b);

    int yu;

    while (b != 0) {
        yu = a % b;
        a = b;
        b = yu;
    }

    printf("最大公约数为 %d\n", a);
```

### 整数分解

**方案选择**
先逆序，再逆序有可能会丢失末尾的零。

**正确程序示例**

```c
    int x;
    scanf("%d", &x);

    int mask = 1;
    int t = x;

    // 第一阶段：确定最高位
    while (t > 9) {
        t /= 10;
        mask *= 10;
    }

    // 第二阶段：从最高位开始提取
    do {
        int d = x / mask;
        printf("%d", d);

        if (mask > 9) {
            printf(" ");
        }

        x %= mask;
        mask /= 10;

    } while (mask > 0);

    printf("\n");
```

- while (t > 9)：判断临时变量是否仍为至少两位数。每轮执行 t /= 10 和 mask \*= 10，直到 t 只剩一位，得到原整数最高位对应的除数。使用 t > 9 而非 t > 0，是为了避免 mask 多乘一次 10。

### 类型转换

### 整数
**位与字节**
- bit（位）：二进制的最小单位，取值为 0 或 1。
- byte（字节）：C 语言中，`char` 的大小始终为 1 字节。
- 常见计算机中，1 字节 = 8 位。
- 8 位共有 2⁸ = 256 种不同组合。

**补码**
现代计算机通常采用补码存储有符号整数。

8 位补码示例：
| 二进制 | 有符号解释 |
|---|---:|
| `00000000` | 0 |
| `00000001` | 1 |
| `01111111` | 127 |
| `10000000` | -128 |
| `11111111` | -1 |

**8 进制和 16 进制**
* 一个以 0 开始的数字字面量是 8 进制。
* 一个以 0x 开始的数字字面量是 16 进制。

**十六进制表示范围**
8 位二进制 = 2 位十六进制 = 00～FF

unsigned：
00～FF → 0～255

signed（8 位补码）：
00～7F →   0～127
80～FF → -128～-1

负数的补码：
-1   → FF
-2   → FE
-5   → FB
-127 → 81
-128 → 80

转换规律：
00～7F：十六进制正常转换
80～FF：先转换为无符号十进制，再减 256

**unsigned**
* unsigned 表示无符号，也就是不使用负数的整数类型。

| 类型 | 数值范围 | 能否表示负数 |
| --- | --- | --- |
| signed char | -128～127 | 能 |
| unsigned char | 0～255 | 不能 |

* 无符号整数的回绕：
- 255 + 1 → 0
- 0 - 1 → 255
- 256 → 0
- 257 → 1

```c
unsigned char a = 255;
a++;                 // a = 0

unsigned char b = 0;
b--;                 // b = 255
```

**整数的输入输出**
* 只有两种形式：int 或 long long
  - %d：int
  - %u：unsigned
  - %ld：long long
  - %lu：unsigned long long

### 字符的输入输出与计算
**字符的输入输出**
C 语言使用 `char` 类型保存字符。
字符在计算机中通过字符编码表示。对于 ASCII 字符，字符可以与其对应的整数编码相互转换。

| 表达式 | 含义 |
|---|---|
| `'1'` | 字符 1，ASCII 值为 49 |
| `1` | 整数 1 |
| `%c` | 输入或输出单个字符 |
| `%d`、`%i` | 在 `printf` 中输出十进制整数 |

直接读取字符：
```c
char c;
scanf("%c", &c);  // 输入 1

printf("%d %c", c, c);
```

输出：
```text
49 1
```

先读取整数编码，再赋给字符变量：
```c
int i;
char c;
scanf("%d", &i);  // 输入 49
c = i;
printf("%c", c);  // 输出 1
```

注意：
- `%c` 读取的是字符，也可能读到空格、换行。
- `scanf(" %c", &c)` 可跳过前面的空白字符。
- `'1'` 不等于整数 `1`。

**字符计算**
字符可以通过对应的编码值进行算术运算。

字符自增：
```c
char c = 'A';
c++;
printf("%c", c);  // B
```

原理：
```text
'A' = 65
'A' + 1 = 66
66 对应 'B'
```

字符相减：
```c
int i = 'Z' - 'A';
printf("%d", i);  // 25
```

原理：
```text
'Z' = 90
'A' = 65
90 - 65 = 25
```
两个字符相减，可以得到它们的编码差值。

**大小写转换**
ASCII 英文字母编码：

| 字符 | 编码范围 |
|---|---|
| `'A'`～`'Z'` | 65～90 |
| `'a'`～`'z'` | 97～122 |

对应大小写字母的编码差为：
```c
'a' - 'A'  // 32
```

大写转小写：
```c
char c = 'B';
c = c + 'a' - 'A';
printf("%c", c);  // b
```

小写转大写：
```c
char c = 'b';
c = c + 'A' - 'a';
printf("%c", c);  // B
```

安全使用时应检查字符范围：
```c
if (c >= 'A' && c <= 'Z') {
    c = c + 'a' - 'A';
}
```

**数字字符与整数转换**
与大小写转换使用相同的原理。

整数转数字字符：
```c
int n = 4;
char c = '0' + n;  // '4'
```

数字字符转整数：
```c
char c = '4';
int n = c - '0';   // 4
```

适用于单个数字 `0～9`。

**易错点**

| 写法 | 结果或说明 |
|---|---|
| `'A' + 1` | 对应 `'B'` 的编码值 |
| `'Z' - 'A'` | 整数 25 |
| `'a' - 'A'` | 整数 32 |
| `'0' + 4` | 对应字符 `'4'` 的编码值 |
| `'4' - '0'` | 整数 4 |
| `'1' == 1` | 不成立 |
| `c++` | 编码值增加 1，不一定得到下一个英文字母 |

核心记忆：
- 字符通过编码值存储和参与计算。
- `%c` 输出字符，`%d` 输出编码对应的整数值。
- 大写转小写：`c + 'a' - 'A'`。
- 小写转大写：`c + 'A' - 'a'`。
- 数字转字符：`'0' + n`。
- 字符转数字：`c - '0'`。
以上字符计算和大小写转换规律，针对 ASCII 英文字母与数字字符。

### 其他运算逻辑
**bool**
* 使用方法：`#include <stdbool.h>`
* 引入后就可使用 bool true/false。
* 示例：`bool b = 6>5;`
* 输出含义：
  - 0 = false（假）
  - 1 = true（真）
  所有非零值都会被转换为 true，而不只是 1。与 if 的判断类似。

**条件运算符与条件表达式**
* ? 前面是条件，? 和 : 之间是条件满足时的值，: 后是条件不满足时的值。
示例：`count = (count > 20) ? count - 10 : count + 10;`

等同于：
```c 
if (count > 20) 
    count = count - 10;
else 
    count = count + 10;
```

* 条件运算符自右向左结合。
* 条件运算符的优先级高于赋值、逗号运算符，但是低于其它运算符。
* 不推荐使用嵌套的条件表达式。

**逗号运算**
* C 语言中，逗号也作为运算符存在，用来连接两个表达式，并以右边表达式的值作为结果。
* 逗号的组合关系是自左向右，因此左边的表达式会先计算。
* 逗号优先级低于其它所有运算符 (含赋值)。
* 示例： i = 3+4, 5+6 输出 7; i = (3+4, 5+6) 输出 11。
* 用途：主要用于 for 循环内的括号。

### 逻辑运算与逻辑表达式
> 关系表达式可以判断一个条件是否成立，而逻辑运算可以把多个条件组合起来。

在 C 中：

- `0` 表示假；
- 非 `0` 表示真；
- 逻辑运算的结果为 `0` 或 `1`。

**逻辑运算符**

| 运算符 | 含义         | 示例             |
| :----: | ------------ | ---------------- | ------------ | ------ | --- | ------ |
|  `&&`  | 逻辑与，并且 | `a > 0 && b > 0` |
|   `||`   | 逻辑或，或者 | `a > 0 |     | b > 0` |
|  `!`   | 逻辑非，取反 | `!(a > 0)`       |

优先级由高到低：

1. `!`
2. 关系运算：`< <= > >=`
3. 相等运算：`== !=`
4. `&&`
5. `||`
6. `=`

例如：`a > 0 && b < 10 || c == 5` 等价于 `(a > 0 && b < 10) || c == 5`

**`&&`：逻辑与**
> 两个条件都成立时，整个表达式才成立。

`a > 0 && b > 0` 表示：a 大于 0，并且 b 大于 0。

| 左边 | 右边 | `&&` 结果 |
| :--: | :--: | :-------: |
|  假  |  假  |    假     |
|  假  |  真  |    假     |
|  真  |  假  |    假     |
|  真  |  真  |    真     |

例如判断一个数是否在 `[80, 90)` 范围：`score >= 80 && score < 90`

**`||`：逻辑或**
> 两个条件中至少有一个成立，整个表达式就成立。
> `a > 0 || b > 0` 表示：a 大于 0，或者 b 大于 0。

| 左边 | 右边 |  `  |     | ` 结果 |
| :--: | :--: | :-: | --- | ------ |
|  假  |  假  | 假  |
|  假  |  真  | 真  |
|  真  |  假  | 真  |
|  真  |  真  | 真  |

例如：`year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)` 表示：能被 400 整除，或者能被 4 整除且不能被 100 整除。

**逻辑非**
> 用于将真假结果反转。

`!a`：如果 `a` 为假，则结果为真；如果 `a` 为真，则结果为假。
例如：`!0` 结果为：`1`，而：`!5` 结果为 `0`。
对整个条件取反：`!(score >= 60)` 表示： `score >= 60` 不成立。

在实际代码中，如果有更直接的关系运算符，通常优先写：`score < 60` 而不是：`!(score >= 60)`

**逻辑表达式**
> 由关系表达式和逻辑运算符组成的表达式，可以用来表示更复杂的条件。
> 例如：`score >= 80 && score < 90` 中：`score >= 80` 和 `score < 90` 都是关系表达式，再通过 `&&` 组合成一个逻辑表达式。

**短路运算**
> 逻辑运算是自左向右进行的，如果左边的结果已经能决定结果，就不会做右边的运算。
> 不要把复合赋值、赋值组合进逻辑运算表达式。

对于：`A && B`，如果 `A` 已经为假，则整个表达式一定为假，因此不会继续计算 `B`。
对于：`A || B`，如果 `A` 已经为真，则整个表达式一定为真，因此不会继续计算 `B`。

**`&` 与 `&&` 不同**
&& 是逻辑与，用于组合条件：a > 0 && b > 0 而单独的 & 还可以表示按位与运算等。

**常见错误**

1. 把赋值 `=` 写成比较 `==`
2. 用单个 `&` 代替 `&&`
3. `||` 两边未写完整条件
4. **数学中的连续比较直接照搬到 C**

## 函数
### 函数的定义和调用
> 函数是一块代码，接受零个或多个参数，做一个事情，返回零个或多个值。
**结构**
```c
返回值类型 函数名(参数类型 参数名)
{
    函数体;
    return 返回值;
}
```
* 函数头：包含返回类型 (如 void 不返回任何结果) + 函数名 (如 sum) + 参数表 (如 int begin, int end)
* 参数表含圆括号，参数之间用逗号分隔，有参数调用时需要给出正确的数量和顺序。
* 函数知道每一次是哪里调用它，会返回到正确的位置。
* 函数定义：用于说明函数可以做什么。函数调用：用于真正执行函数。

**示例**
```c
int add(int a, int b) {  // 定义函数
    return a + b;
}

int main() {
    int result = add(2, 3);  // 调用函数
    printf("%d\n", result);

    return 0;
}
```

**从函数中返回**
* return: 若函数需要返回结果时使用，把结果交给需调用的地方。
  - 作用：停止函数的执行，并返回一个值 (给后续代码)。返回类型与函数头中相同。
  - 使用方法 `return;` 或 `return 表达式;`。
  - return 尽可能遵守单一出口原则。
* 调用函数目的不一定是看返回结果，有时候可能会需要它做一些其它事项。
* void 不能使用带值的 return，但可以不含 return，另外调用时不能做返回值的赋值。

### 函数的参数和变量
**函数先后关系**
* C 的编译器自上而下分析代码。因此一般要调用的函数写在开头 (主函数前)。
* 若需要后置函数主体部分，则必须让函数声明 (函数声明 含分号) 在开头，在之后对函数进行定义 (编译器会检查定义与声明的一致性)。
* 函数声明：函数头以分号结尾，就构成了函数声明。用于告诉编译器函数长什么样。一般写在 (主) 函数的外面。
* 编译器做检查时检查参数类型，但不检查参数名称。因此声明中参数名称与定义不一致仍可正常编译。

**参数传递**
* 如果函数有参数，调用函数时必须传递给它数量、类型正确的值。
* 可以传递给函数的值是表达式的结果。包括字面量、变量、函数的返回值、计算结果。
* 若传递的值与参数类型不匹配，编译器通常会自动转换，但可能得到非预期结果。
* C 语言在调用函数时，永远只能传值给函数。传递的只是副本，而不是变量本身。
  - 例如：引入一个新变量交换两个数无法直接利用函数实现，需要借助指针。
* 每个函数有自己的变量空间，参数也位于这个独立的空间中，与其他函数无关。函数间不会因为变量同名就共享同一份数据。
* 函数参数表中的参数叫做 "(形式) 参数"，调用函数时给的值叫做"实际参数 / 值" (实际参数 != 实际在函数中进行运算的参数)。

**本地变量**
* 定义在函数内部的变量就是本地变量。参数也是本地变量。
* 本地变量不会被默认初始化。参数在进入函数前需要定义/初始化。
* 变量的生存期和作用域 (受限于包含的大括号)
  - 生存期：什么时候这个变量开始出现了，到什么时候它消亡了。
  - 作用域：在什么范围内可以访问这个变量 (这个变量可以起作用)。
* 全局变量与局部变量
  - 局部变量只在包含它的大括号 (作用域) 内生效，并且遮蔽全局变量。
  - 把变量定义在 main() 外面，它们就成为全局变量。
  - 因此，不同块内允许定义同名变量，而同一个块内不能。

**函数庶事**
* `void f(void)`：明确表示函数不接收任何参数。
* `void f()`：表示函数参数表未知，不代表没有参数。
* 编写函数时，尽可能把函数原型写全，若无参数，写上 void。
* C 语言不允许函数的嵌套定义。只能在一个函数里放另一个函数的声明，但不能出现定义。
* `return 0;`：用于 main 函数把 0 返回给调用它的地方 (如证明函数正常退出)，不能删除。

## 数组
### 数组的定义与使用
**一般格式**
`<类型> 变量名称[元素数量];` 
举例：`int grades[100];` `double weight[20];`
* 元素数量必须是整数
* C99 前元素数量必须是编译时确定的字面量 不能是变量 (程序运行过程中产生的数)

**特征**
1. 数组中所有的元素具有相同的数据类型。
2. 数组一旦创建，大小不可改变。
3. 数组中元素在内存中是连续依次排列的。

**单元**
* `int a[10]` 包含 10 个单元：a[0], a[1], ..., a[9]。每个单元就是一个 int 类型的变量。
* 由上例可知：数组的每个单元就是数组类型的一个变量。
* 单元可以出现在赋值的左右两侧 (`a[2]=a[1]+6`)。在赋值左边的叫做左值。
* 在赋值号右侧行为：读取值；左侧行为：写入。
* 使用数组时放在 [] 中的数字叫做下标/索引，下标从 0 开始计数。
* 有效的下标范围: [0, 数组的大小-1] (编译器不会核验)。
* 长度为 0 的数组可以存在，但没有作用。

**示例：统计个数**
* 写一个程序，输入数量不确定的 [0, 9] 范围内的整数，统计每一种数字出现的次数，输入 -1 表示结束。
代码参考：
```c
    const int number = 10; // const 表明变量不可经普通赋值修改
    int x; // 用户输入数
    int count[number]; // 定义数组
    int i; // 计数器

    for (i = 0; i < number; i++) {
        count[i] = 0; // 初始化数组 让所有计数器从 0 开始
    }

    // int count[i] = {0}; 另一种初始化方式

    scanf("%d", &x);
    while (x != -1) { // 不满足结束条件则继续读取
        if (x >= 0 && x <= 9) {
            count[x]++; // 核心运算 将对应数字的出现次数 +1
        }
        scanf("%d", &x);
    }

    for (i = 0; i < number; i++) { // 遍历数组
        printf("%d:%d\n", i, count[i]); // 输出数字及其出现的次数
    }
```

### 数组运算
**数组的集成初始化**
* 使用例：`int a[] = {2,4,6,7,1,3,5,9,11,13,23,14,32};`
* 直接用大括号给出数组的所有元素的初始值。不需要给出数组的大小。

**集成初始化的定位**
int a[10]={[0] = 2, [2] = 3, 6};
* 用 [n] 在初始化数据中给出定位。
* 没有定位的数据接在前面的位置后面 (如上 a[3] = 6)，其他位置的值补零。
* 可以不给出数组大小，适合初始数据稀疏的数组。

**数组的大小**
* 对数组使用 sizeof，便可以得知数组内有多少个字节。
* 将 sizeof 数组的结果除去 sizeof 第一个单元的结果 (如 `sizeof(a)/sizeof(a)[0]`，便可以得知数组内的单元数目。
* 利用 sizeof 优点：修改初始数据时，无需修改遍历代码。

**数组的赋值**
* 数组变量本身不能被赋值。
* 要把一个数组的所有元素交给另一数组，必须遍历。

**遍历数组**
* 一般采用 for 循环。
* 让循环变量 i 从 0 到小于数组的长度，循环体内最大 i 正好是数组最大的有效下标。
* 遍历长度为 N 的数组：`i = 0; i < N; i++`。


**数组作为函数参数 (传参)**
* 定义用 `a[]`，传参用 `a`，访问元素用 `a[i]`。
* 将已有数组交给函数处理，无需重新输入、初始化或复制全部元素。示例：
```c
#include <stdio.h>

int sumArray(int a[], int length)
{
    int sum = 0;
    for (int i = 0; i < length; i++) {
        sum += a[i];
    }
    return sum;
}

int main(void)
{
    int a[] = {3, 5, 2, 8, 4};
    int length = sizeof(a) / sizeof(a[0]);

    printf("%d", sumArray(a, length));
    return 0;
}
```

输出：`22`

* 数组传参不会复制整个数组，函数访问的是原数组元素。
* 数组形参 `int a[]` 等价于 `int *a`（指针）。
* 函数无法仅凭数组形参自动知道原数组长度，因此通常需要额外传入 `length`。
* `sizeof(a) / sizeof(a[0])` 应在原数组所在作用域计算，不能在接收数组的函数内部用同样方式求原数组长度。
* 函数可以读取、修改原数组元素；修改数组元素与修改普通数值形参不同。
* 读取元素前必须确保它已经赋值，例如由 main 中的 scanf 成功读入。

**示例：顺序查找**
```c
int search(int key, int a[], int length);

int main(void)
{
    int a[] = {2, 4, 6, 7, 1, 3, 5, 9, 11, 13, 23, 14, 32};
    int x;
    int loc;

    printf("请输入一个数字：");
    scanf("%d", &x);

    loc = search(x, a, sizeof(a) / sizeof(a[0]));

    if (loc != -1) {
        printf("%d在第%d个位置上\n", x, loc);
    } else {
        printf("%d不存在\n", x);
    }

    return 0;
}

int search(int key, int a[], int length) // 要寻找的数字 要搜索的数组 数组元素数量
{
    int ret = -1; // 表示尚未找到
    int i;

    for (i = 0; i < length; i++) {
        if (a[i] == key) { // 搜索结果匹配
            ret = i;
            break;
        }
    }

    return ret;
}
```

* 数组作为函数的参数时: 不能在 [] 中给出数组的大小，不能再利用 sizeof 来计算数组的元素个数。

**示例：埃式筛判断素数**
```c
#include <stdio.h>

int main()
{
    const int maxNumber = 25;
    int isPrime[maxNumber];
    int i;
    int x;

    // 1. 初始化：先假设所有数字都是素数
    for (i = 0; i < maxNumber; i++) {
        isPrime[i] = 1;
    }

    // 2. 筛选：排除合数
    for (x = 2; x < maxNumber; x++) {
        if (isPrime[x]) {
            for (i = 2; i * x < maxNumber; i++) {
                isPrime[i * x] = 0;
            }
        }
    }

    // 3. 输出：剩下的素数
    for (i = 2; i < maxNumber; i++) { // 0 和 1 均不是素数
        if (isPrime[i]) {
            printf("%d\t", i);
        }
    }

    printf("\n");
}
```

### 二维数组
* 示例：`int a [3][5]` 可以看作 a 是一个 3 行 5 列的矩阵。

**二维数组的遍历**
示例：
```c
for (i=0;i<3;i++) {
    for (j=0;j<5;j++) {
        a[i][j] = i*j;
    }
}
```
* a [i][j] 便表示第 i 行第 j 列上的单元。
*不要写成 a[i, j]，这表示 a[j] (逗号是运算符)。

**二维数组的初始化**
示例：
```c
int a[][5] = {
    {0,1,2,3,4}, // a0
    {2,3,4,5,6}, // a1
}
```
* 列数不可省略，行数可以省略 (编译器数)。
* 每行包含一个大括号，用逗号分隔。
* 中间省略表示补 0。

## 指针
### 取地址运算

**运算符 &**
* 作用：获得变量的地址，因此它的操作数必须是变量。
* 使用例：
```c
int i; 
scanf("%d", &i); 
// printf("0x%x", &i); 以 16 进制输出值
printf("%p", &i); // 输出内存地址 在 32 位编译情况下 输出与前者相同
```
